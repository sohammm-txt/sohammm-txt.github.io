Python AES-256-GCM PBKDF2 CLI

PyPassVault

A command-line password manager built with Python. Encrypts credentials with AES-256-GCM so your passwords stay protected.

  • Encrypts credentials with AES-256-GCM, with keys derived using PBKDF2 (100,000 iterations, random salt)
  • Fresh random nonce for every encryption operation
  • Categorized vault files and built-in password generator using Python's secrets module
  • Self-destructs the vault after 20 wrong master password attempts to thwart brute force
  • Includes an automated test suite (python3 tests.py)

Steganography Tool

Hides secret text payloads inside PNG images using Least Significant Bit (LSB) steganography.

  • Works with any language through complete UTF-8 encoding support
  • Handles RGB, grayscale, palette, and RGBA images transparently
  • Automated payload capacity check and configurable stop marker detection
  • Clean interactive terminal menu interface built with Pillow
  • Image looks visually identical to the naked eye after embedding secret text
